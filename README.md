# Simple Expense Tracker

A beginner-friendly Python project to record expenses and calculate total spending.

## Features
- Add new expenses
- View all expenses
- Calculate total spending
- Exit the program using a menu option

## Python Concepts Used
- Variables and user input
- Lists and dictionaries
- `while` and `for` loops
- `if`, `elif`, and `else`
- Basic calculations

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run `python expense_tracker.py`.
4. Follow the menu instructions.
